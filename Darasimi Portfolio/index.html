Hi, I'm Adegboye Darasimi Busayo, a passionate Front-End Developer focused on building clean, accessible, and performant web interfaces. I believe great code and great design are inseparable.

My approach combines strong fundamentals in HTML, CSS, and JavaScript with modern tools like React and Next.js to deliver user experiences that feel intuitive and delightful. I care deeply about responsive design, semantic markup, and pixel-perfect implementation.

I'm continuously learning, collaborating, and pushing myself to write better code, whether that's through open-source contributions, team projects, or building my own ideas from scratch.
